### Что делаю

**LLM и агенты.** Собрал локальный прокси между клиентом и языковой моделью — со счётчиками токенов, логами расхода и обходом проблем с сертификатами. Поверх него — конвейер из агентов на бесплатных провайдерах: читают код, сжимают большие модули, ищут баги. Всё работает на нулевой стоимости, лимиты провайдеров измерены опытным путём.

**Telegram-боты.** Приём фото и сообщений, диалог с памятью, очередь задач. Отдельный демон читает личную переписку и отдаёт её только по запросу — никаких фоновых расходов и лишних запросов к модели.

**Discord-боты.** Музыкальные и модерационные боты на `discord.js` — часть учебные, часть написана для реальных серверов. Самый ранний датируется 2021 годом.
